2. 我們收集哪些資料、為什麼收集

類別具體資料用途必要？儲存位置
帳號 Google 帳號 email、顯示名稱、大頭貼 URL 家庭共享（建立/加入家庭、辨識成員） 否 — 可純本機使用、不登入 Firebase Authentication
家庭資料 家庭名稱、邀請碼、成員名單 家庭共享 否 — 同上 Cloud Firestore
共享訂閱快照 你選擇分享的訂閱名稱、價格、扣款日 讓其他家庭成員看見並分攤成本 否 — 純本機使用時無此資料 Cloud Firestore
本機訂閱資料 手動新增的訂閱（名稱、價格、扣款日、分類） App 核心功能 — 追蹤訂閱與扣款 是 裝置本機（SQLite）
本機提醒 你設定的提醒時間 排定本地通知 是 裝置本機
Gmail 信箱讀取 在 App 內點「連結 Gmail」時，讀取郵件標頭與 snippet（From/Subject/Date/Snippet） AI 解析收據、自動建立訂閱清單 否 — 手動新增即可 直接呼叫 Cloudflare Worker → DeepSeek；郵件內容不儲存於伺服器
推播 token FCM token 在裝置上推播提醒 否 — 關閉通知即可停止 Firebase Cloud Messaging
使用分析 事件名稱與參數（如 app_open、subscription_added） 了解功能使用狀況、改進產品 否 — 可在系統設定關閉 Firebase Analytics

3. 我們不做的事

  • 不儲存你的 Gmail 郵件內容（Worker 即時解析、回傳後丟棄）
  • 不賣你的資料給第三方
  • 不投放個人化廣告
  • 不在背景自動掃描（AI 匯入只在你點按時觸發）

服務收到的資料隱私權政策

5. 你的選擇與權利

  • 刪除資料：聯絡 wongo.w@gmail.com（App 內刪除功能規劃中）
  • 撤回 Gmail 授權：到 Google 帳戶安全性 → 第三方應用程式 撤銷
  • 關閉推播：系統設定 → 通知 → 訂閱管家
  • 關閉分析：系統設定 → 隱私 → 追蹤
  • 匯出資料：聯絡 wongo.w@gmail.com
  • 被遺忘權（GDPR / APPI）：聯絡 wongo.w@gmail.com，30 天內處理

6. 兒童
